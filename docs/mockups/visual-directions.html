Dead Zone RTS — visual direction mockups

Direction A "Darkest Night" + low-rez 3/4 pixel art. All art here is placeholder-quality but built the same way the game will build it (pixel sprites + lighting layer).
A. Daytime — 3/4 oblique pixel art. Square grid unchanged; buildings get roofs + front faces, units/zombies are upright sprites. Cabin, dumpster and wrecked car are searchable caches; note the dormant zombie slumped beside the car.
B. Same scene at night. Ambient darkness, warm light pool at the HQ, small flashlight radii on units, and a signal flare burning at the right — the horde drifts toward it instead of the walls.
C. Fog of war. Left: visible (live). Middle: explored — remembered terrain and structures, dimmed, no live entities. Right: unexplored black. At night the visible band shrinks to your light radii.
D. True isometric (comparison — rejected). Same content on a diamond grid. Looks good, but every world↔screen transform, hit-test, and the placement UX changes with it; the spec rejects it in §9. If this look is worth that cost to you, say so now.
Everything above is procedural — no image files. The real game renders sprites from compact pixel-data strings into an atlas once at load (js/sprites.js), then draws the lighting as one offscreen composite per frame. Want to see the neon-vector direction mocked up too, or palette variants (colder/warmer night, more/less saturated grass)? Easy to add.
