Production path

One source model

Rig the selected low-poly unit once. Animate limbs, tools, and weapons, then render each heading from a locked orthographic camera.

One pixel budget

Render transparent frames, reduce them to the chosen native grid, and manually clean silhouettes. Keep the same crop and foot anchor in every frame.

One playback contract

Pack PNG atlases with frame rectangles, anchor, duration, and looping metadata. Test every state transition, facing change, and loop at normal zoom and night lighting.

The pilot uses a deterministic pixel rig to prove continuity. It shares front, back, side, and mirrored shapes; production-quality eight-direction art still needs authored or 3D-rendered views for each heading.
